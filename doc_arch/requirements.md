# 機能要件

## この文書について

全体像は [overview.md](./overview.md) を参照。本書は「何を実現したいか（要件）」だけを扱い、
それを実現する方式（アーキテクチャ）は [backend.md](./backend.md) / [frontend.md](./frontend.md) を参照。

## 1. MVP スコープ

- [ ] レベル一覧の閲覧（未ログインでも閲覧・プレイ可能＝読み取りは公開）
- [ ] レベルの作成・投稿（背景画像・ブロック配置・ブロック画像・タイトル）
- [ ] 投稿には最低限の認証が必要（匿名連投・荒らし対策。認証方式は [backend.md](./backend.md) 参照）
- [ ] 画像はアップロード時にサイズ・形式を検証（[backend.md](./backend.md) §6）

## 2. 将来拡張（本書では設計のみ、実装スコープ外）

- パドルサイズ・ボール速度・初期ライフ数などゲームバランス系パラメータの外部化
  （`config.rs` の該当定数を injection 対象に追加）
- いいね／プレイ回数によるランキング・ソート
- タグ・検索
- レベルの通報・非表示（モデレーション）
- ユーザープロフィール・自分の投稿一覧

## 3. 未決事項・要確認（要件側）

- [ ] 投稿に認証を必須にするか、匿名投稿を許容するか（荒らし対策とのトレードオフ）
- [ ] 画像・レベルデータの上限サイズ／点数（ブロック数上限など）の具体値
- [ ] モデレーション（通報・削除）を MVP に含めるか、後回しにするか
